# SwiftSFTP Explorer — คู่มือภาษาไทย

โปรแกรมจัดการไฟล์บนเซิร์ฟเวอร์ผ่าน SFTP สำหรับ Windows 10/11 หน้าตาและการใช้งานคล้าย Windows
File Explorer แต่ทำงานกับไฟล์บนเซิร์ฟเวอร์จริงผ่าน SSH ทุกคำสั่งทำงานใน Rust ไม่ใช่แค่หน้าจอจำลอง

---

## 1. สิ่งที่ต้องมี

- Windows 10 หรือ Windows 11 (64-bit)
- WebView2 Runtime (ตัวติดตั้งจะดาวน์โหลดให้อัตโนมัติหากเครื่องยังไม่มี)
- **ไม่ต้องติดตั้ง** Rust, Node.js, npm หรือ Visual Studio บนเครื่องปลายทาง

## 2. การติดตั้ง

1. เปิดโฟลเดอร์ `release/windows/`
2. ดับเบิลคลิก **`SwiftSFTP-Setup.exe`**
3. เลือกตำแหน่งติดตั้ง และเลือกว่าจะสร้างทางลัดบน Desktop / Start Menu หรือไม่
4. กด **Install** แล้วรอจนเสร็จ
5. ติ๊ก **Launch SwiftSFTP Explorer** แล้วกด **Finish**

> ไฟล์ติดตั้งในโปรเจกต์นี้ **ยังไม่ได้ลงลายเซ็นดิจิทัล (Code Signing)** ดังนั้น Windows SmartScreen
> อาจขึ้นเตือน "Windows protected your PC" ให้กด **More info → Run anyway**
> โปรแกรมไม่ได้ปิดระบบความปลอดภัยของ Windows ใด ๆ ทั้งสิ้น

### การถอนการติดตั้ง

ไปที่ Settings → Apps → Installed apps → SwiftSFTP Explorer → Uninstall
หรือใช้ไฟล์ `uninstall.exe` ในโฟลเดอร์ที่ติดตั้ง

การถอนการติดตั้งจะลบไฟล์โปรแกรม แต่ **ไม่ลบข้อมูลผู้ใช้** (โปรไฟล์เซิร์ฟเวอร์และรายการโปรด)
หากต้องการลบข้อมูลทั้งหมด ให้ไปที่ Settings → Advanced → Factory reset ก่อนถอนการติดตั้ง

## 3. การเชื่อมต่อเซิร์ฟเวอร์ครั้งแรก

1. กดปุ่ม **+** ที่แถบด้านซ้าย หรือ **Ctrl+T**
2. กรอกข้อมูล
   - **ชื่อโปรไฟล์** เช่น `Minecraft Production`
   - **Host / IP** และ **Port** (ค่าเริ่มต้น 22)
   - **ชื่อผู้ใช้**
   - **วิธีตรวจสอบสิทธิ์**
     - `Password` — รหัสผ่าน (บันทึกแบบเข้ารหัสด้วย Windows DPAPI)
     - `Private key file` — เลือกไฟล์คีย์ เช่น `C:\Users\you\.ssh\id_ed25519` และใส่ passphrase หากมี
     - `SSH agent` — ใช้ Windows OpenSSH agent (ต้องรัน `ssh-add` โหลดคีย์ก่อน)
   - **โฟลเดอร์เริ่มต้น** (ไม่บังคับ) เช่น `/home/minecraft`
3. กด **Test connection** เพื่อทดสอบ (ไม่บังคับ)
4. กด **Connect**

### การตรวจสอบ Host Key (สำคัญด้านความปลอดภัย)

ครั้งแรกที่เชื่อมต่อกับเซิร์ฟเวอร์ โปรแกรมจะแสดง **ลายนิ้วมือ SHA-256** ของ Host Key และให้คุณเลือก

- **Trust and remember** — เชื่อถือและจดจำ (แนะนำเมื่อตรวจสอบลายนิ้วมือกับผู้ดูแลเซิร์ฟเวอร์แล้ว)
- **Trust once** — เชื่อถือเฉพาะครั้งนี้
- **Reject** — ยกเลิกการเชื่อมต่อ

หาก Host Key **เปลี่ยนไปจากเดิม** โปรแกรมจะเตือนเป็นสีแดงและไม่ยอมเชื่อมต่อโดยอัตโนมัติ
ให้ตรวจสอบกับผู้ดูแลเซิร์ฟเวอร์ก่อนกดยอมรับ

ตรวจลายนิ้วมือบนเซิร์ฟเวอร์ได้ด้วยคำสั่ง

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

## 4. การใช้งานหน้าจอ

### แท็บ (Tab Bar)
- เปิดหลายแท็บได้พร้อมกัน แต่ละแท็บใช้ **การเชื่อมต่อ SSH เดิมร่วมกัน** ไม่ต้องล็อกอินซ้ำ
- `Ctrl+T` เปิดแท็บใหม่, `Ctrl+W` ปิดแท็บ, `Ctrl+Tab` สลับแท็บ
- คลิกกลางเมาส์เพื่อปิดแท็บ, ลากแท็บเพื่อสลับตำแหน่ง, ดับเบิลคลิกเพื่อทำสำเนาแท็บ

### แถบนำทาง (Navigation Bar)
- ปุ่มย้อนกลับ / ไปข้างหน้า / ขึ้นหนึ่งระดับ / รีเฟรช
- คลิกที่แถบที่อยู่เพื่อพิมพ์ path โดยตรง (มี autocomplete ชื่อโฟลเดอร์)
- ช่องค้นหาทางขวา: พิมพ์แล้วกด Enter เพื่อค้นหาแบบไล่โฟลเดอร์ย่อย

### รายการไฟล์
- เลือกได้หลายไฟล์: `Ctrl+คลิก` และ `Shift+คลิก`
- ดับเบิลคลิกโฟลเดอร์เพื่อเปิด, ดับเบิลคลิกไฟล์ข้อความเพื่อเปิดในตัวแก้ไข
- คลิกขวาเพื่อเมนู: เปิด, ดาวน์โหลด, คัดลอก, ตัด, วาง, เปลี่ยนชื่อ, สิทธิ์, ลบ, ปักหมุด
- สลับมุมมอง Details / List / Grid ได้ที่ปุ่มมุมขวาบน
- ลากไฟล์จาก Windows Explorer มาวางในหน้าต่างเพื่ออัปโหลด (มีแถบไฮไลต์บอกโฟลเดอร์ปลายทาง)

### แผงการถ่ายโอน (Transfers)
เปิดด้วย `Ctrl+J` หรือปุ่มที่มุมขวาบน แสดง
ชื่อไฟล์, ต้นทาง → ปลายทาง, ขนาด, ความเร็วจริง, เปอร์เซ็นต์, เวลาที่เหลือ, วิธีที่ใช้, สถานะ
และปุ่มหยุดชั่วคราว / ทำต่อ / ยกเลิก / ลองใหม่

### ตัวแก้ไขไฟล์
รองรับ `.txt .json .yaml .yml .toml .xml .properties .conf .ini .sh .log` และอื่น ๆ
มีไฮไลต์สี, เลขบรรทัด, ค้นหา/แทนที่, `Ctrl+S` บันทึก
หากไฟล์ถูกแก้ไขบนเซิร์ฟเวอร์ระหว่างที่คุณเปิดอยู่ โปรแกรมจะแจ้งเตือนก่อนเขียนทับ

## 6. การตั้งค่า

- **General** — ภาษา (ไทย/อังกฤษ), พฤติกรรมตอนเปิดโปรแกรม, เปิดแท็บเดิม, ถามก่อนลบ
- **Appearance** — ธีม (ตามระบบ/มืด/สว่าง), มุมมองไฟล์, แถวกระชับ, แอนิเมชัน, แสดงไฟล์ซ่อน
- **Performance** — จำนวนการถ่ายโอนพร้อมกัน, ขนาดบัฟเฟอร์, จำกัดความเร็ว, timeout, keepalive
- **Security** — อนุญาตคำสั่งฝั่งเซิร์ฟเวอร์ (cp/mv), ตรวจ SHA-256, รายการ Host Key ที่เชื่อถือ,
  ล้างรหัสผ่านที่บันทึกไว้
- **Advanced** — ดูบันทึก (log), ส่งออก/นำเข้าการตั้งค่า, คืนค่าเริ่มต้น, Factory reset

### เกี่ยวกับความปลอดภัยของรหัสผ่าน
รหัสผ่านและ passphrase ถูกเข้ารหัสด้วย **Windows DPAPI** ของผู้ใช้ Windows ปัจจุบัน
จัดเก็บในฐานข้อมูลเฉพาะที่ (ไม่ใช่ plain text) และไม่ถูกเขียนลง log
หากคัดลอกโฟลเดอร์ข้อมูลไปเครื่องอื่นหรือเปลี่ยนผู้ใช้ Windows รหัสผ่านเดิมจะใช้ไม่ได้
(ต้องกรอกใหม่)

## 7. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
| --- | --- |
| SmartScreen เตือน | ไฟล์ยังไม่ลงลายเซ็น → More info → Run anyway |
| เชื่อมต่อไม่ได้ (timeout) | ตรวจ firewall/พอร์ต, เพิ่มค่า Connection timeout ในโปรไฟล์ |
| Authentication failed | ตรวจ username/รหัสผ่าน/คีย์, หากใช้คีย์ต้องเป็นรูปแบบ OpenSSH และโหลดเข้ากับ agent ถูกต้อง |
| Host key changed | อาจมีผู้ดักฟัง หรือผู้ดูแลเปลี่ยนคีย์เซิร์ฟเวอร์ — ตรวจสอบก่อนยอมรับ |
| อัปโหลดช้า | เพิ่มจำนวนการถ่ายโอนพร้อมกัน / ขนาดบัฟเฟอร์ ในหน้า Performance |
| เปิดไฟล์ไม่ได้ | ไฟล์ใหญ่เกิน 8 MB หรือไม่ใช่ข้อความ (ตัวแก้ไขไม่รองรับไฟล์ไบนารี) |

## 8. ข้อจำกัดที่ทราบ

ดูรายละเอียดใน `release/KNOWN_LIMITATIONS.md` สรุป:

- ยังไม่ได้ลงลายเซ็นดิจิทัล
- SSH agent รองรับเฉพาะ Windows OpenSSH agent pipe
- ลากไฟล์จากโปรแกรมออกไปยัง Windows Explorer ยังไม่รองรับ (ลากเข้าได้)
- การหยุดชั่วคราว/ทำต่อใช้ได้ในเซสชันปัจจุบัน ไม่กู้คืนหลังปิดโปรแกรม
- ตัวแก้ไขบันทึกเป็น UTF-8 เสมอ

## 9. การสร้างไฟล์ติดตั้งเอง

```bash
pnpm install
pnpm tauri build
```

ไฟล์ที่ได้:
- `src-tauri/target/release/swiftsftp.exe`
- `src-tauri/target/release/bundle/nsis/SwiftSFTP Explorer_1.0.0_x64-setup.exe`

จากนั้นรัน `bash scripts/package-release.sh` เพื่อคัดลอกและเปลี่ยนชื่อเป็น
`release/windows/SwiftSFTP-Setup.exe` พร้อมสร้าง `SwiftSFTP-Portable.zip`
